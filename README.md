# codex-demo

這是一個使用 Next.js App Router 建立的專案骨架。

## 開始使用

1. 安裝依賴：
   ```bash
   npm install
   ```
2. 啟動開發伺服器：
   ```bash
   npm run dev
   ```
3. 在瀏覽器開啟 <http://localhost:3000>

## 可用指令

- `npm run dev`：啟動開發模式
- `npm run build`：建立正式版本
- `npm run start`：啟動正式伺服器
- `npm run lint`：執行 ESLint

## 說明

由於目前環境無法存取 npm registry，本次以手動方式建立專案檔案；待你在可連線環境執行 `npm install` 後即可開始使用。
